## Instrucciones para correr el proyecto

Para ello tienes que tener instalado Node.js y npm.

1. Abre la carpeta del proyecto en VS Code.

2. Abre la terminal y ejecuta:

   ```
   npm install
   ```

3. Cuando acabes, ejecuta:

   ```
   npm run dev
   ```

4. Abre Chrome o el navegador que prefieras y entra a:

   ```
   http://localhost:5173/
   ```

## Controles

* **Flecha de Arriba y Abajo:** Usalas para mover el cañon del tanque.
* **Flecha Izquierda y Derecha:** Usalas para mover el tanque.
* **1, 2 y 3:** Con estos puedes cambiar la fuerza del disparo.
* **Espacio:** Con esta tecla disparas.
* **R:** Se reinicia todo.

## De que trata el juego

En este juego movemos un tanque de izquierda a derecha y podemos cambiar el angulo del cañon y la fuerza del disparo para intentar darle a los 3 objetivos.

El tanque tambien tiene 3 barras verdes que nos muestran la fuerza que estamos usando.
